# game
Compilación — para Linux, macOS y Windows, cada una con CMake, Make y comando manual. Antes de todo explica lo de miniaudio con el comando exacto para descargarlo en cada sistema operativo, y aclara que sin él el juego compila igual pero sin sonido.
Innovaciones — cuatro secciones, cada una con las tres preguntas que pide el parcial:

IA diferenciada — explica la lógica del novio con memoria vs la conciencia con rango infinito, con fragmento de código incluido
Sonido procedural — explica qué es miniaudio, cómo se genera cada sonido matemáticamente y cómo el latido acelera según distancia
Narrativa integrada a la mecánica — explica los tres sistemas: diálogos por habitación, dos pantallas de muerte distintas y typewriter
Timer con mejor marca — explica la implementación cross-platform y la persistencia en archivo
